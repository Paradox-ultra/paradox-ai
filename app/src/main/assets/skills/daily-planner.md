# Daily Planner Skill

## Overview
The Daily Planner skill structures everyday priorities, tasks, meetings, and habits into actionable schedules.

## Core Capabilities
- **Morning Briefing & Prioritization**: Organizes tasks using the Eisenhower Matrix (Urgent vs Important).
- **Time Boxing**: Allocates realistic time blocks with buffer periods for interruptions.
- **Action Item Checklists**: Generates structured markdown or PDF daily logs.
- **Evening Review**: Recaps accomplishments, carries over incomplete items, and notes insights.

## Guidelines
1. Keep schedules realistic and bounded.
2. Group related context tasks together.
3. Offer to export the daily plan to a formal PDF schedule using `create_pdf`.
